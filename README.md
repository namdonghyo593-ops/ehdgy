# 창공의 에이스

브라우저에서 바로 하는 태평양 공중전 게임입니다. 파일 하나(`index.html`)로 돌아가며 서버가 필요 없습니다.

- 캠페인 8챕터 40판 + 챕터별 특별 작전 8개
- 붉은 매 보스전, 별 3개 평가, 조종사 훈련
- **1:1 대전**: 상대 항공모함을 먼저 격침하면 승리 (제한 시간 3분)

## GitHub Pages로 올리기

1. GitHub에서 새 저장소를 만듭니다 (예: `skyace`, Public).
2. `index.html`과 `README.md`를 저장소 맨 위(루트)에 올립니다.
   - 웹에서: 저장소 화면 → **Add file → Upload files** → 두 파일을 끌어다 놓고 **Commit changes**
3. 저장소 **Settings → Pages**로 갑니다.
4. **Source**를 `Deploy from a branch`, **Branch**를 `main` / `/ (root)`로 고르고 **Save**.
5. 1~2분 뒤 `https://<내 아이디>.github.io/skyace/` 주소로 접속됩니다.

## 1:1 대전 하는 법

1. 두 사람 모두 위 주소를 엽니다 (PC·휴대폰 모두 가능, 서로 다른 와이파이여도 됨).
2. 한 사람이 **대전 → 방 만들기**를 누르면 5자리 코드가 나옵니다.
   **초대 링크 복사**로 링크를 보내면 상대는 링크만 열어도 바로 참가됩니다.
3. 다른 사람은 **대전 → 방 참가**에 코드를 넣고 **참가**.
4. 각자 오른쪽에서 기체를 고르고, 방장이 **대전 시작**.

### 규칙
- 상대 항공모함을 먼저 격침하면 승리
- 3분이 지나면 항모 내구도가 더 많이 남은 쪽이 승리 → 같으면 격추 수 → 그래도 같으면 무승부
- 격추돼도 5초 뒤 내 항모에서 재출격, 내 항모 위에서 수리·폭탄 재보급
- 모든 기체를 개량 없는 기본 성능으로 사용 (공정한 대전)
- 항모 대공포가 서로를 지키므로 저공 비행(S/↓)으로 파고들기

### 연결 방식과 한계
- 서버 없이 브라우저끼리 직접 연결(WebRTC)합니다. 처음 연결을 이어 주는 데만 무료 공개 서버(PeerJS)를 씁니다.
- 방장 브라우저가 전투를 계산하고, 참가자는 조작을 보내고 화면을 받습니다. 그래서 참가자 쪽에 아주 약간의 입력 지연이 있습니다.
- 일부 회사·학교·공용 와이파이는 직접 연결을 막아서 "방을 찾지 못했습니다"가 뜰 수 있습니다. 이때는 휴대폰 데이터로 바꿔 보세요.
- 연결이 8초 넘게 끊기면 경기는 "연결 끊김"으로 끝나고 전적에 기록되지 않습니다.

### 혼자 테스트하기
주소 뒤에 `?localnet=1`을 붙여 **같은 브라우저의 탭 두 개**로 열면, 인터넷 연결 없이 한 컴퓨터에서 방장과 참가자를 둘 다 해볼 수 있습니다.
예: `https://<내 아이디>.github.io/skyace/?localnet=1`

## 조작
| PC | 모바일 |
|---|---|
| 마우스 이동·A/D 선회, 좌클릭·Space 사격 | 왼쪽 화면 끌기로 조종 |
| Shift·W 가속, S·↓ 저공 비행 | 오른쪽 버튼: 사격·폭탄·로켓·가속·저공 |
| 우클릭·B 폭탄, R 로켓, Esc 일시정지 | |

진행 상황은 브라우저에 자동 저장됩니다. **설정 → 저장 코드**로 다른 기기에 옮길 수 있습니다.
